# Chrome Web Store — material de publicação

## Nome

OEM Precificação ML

## Resumo curto

Avaliações internas de margem, preço mínimo e promoções do Mercado Livre para a equipe OEM Parts.

## Descrição

Ferramenta interna e somente leitura que mostra, nas telas de preços e promoções do Mercado Livre, a recomendação calculada pelo OEM Dash. Cada badge informa se a oportunidade é recomendada, exige revisão, deve ser evitada ou está bloqueada por dados incompletos. O popover detalha contribuição, tarifa, frete, custo, impostos, preço mínimo e preço-alvo.

A extensão não muda preços, não aceita promoções e não executa ações comerciais na conta. A URL da API e a chave de acesso são configuradas pelo usuário e armazenadas localmente no navegador.

## Uso de dados

- Finalidade única: funcionalidade de precificação e avaliação de promoções.
- Dados processados: IDs de anúncios/campanhas e preços comerciais visíveis na página.
- Armazenamento local: URL da API e chave interna.
- Compartilhamento: somente com a API OEM configurada; sem venda, publicidade ou terceiros.
